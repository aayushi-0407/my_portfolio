AI Chatbot for 5G Network Automation

AI/ML 5G Networks NLP

An advanced chatbot designed to streamline the complex process of configuring 5G network components. Leveraging the power of the Mistral Large Language Model, this tool interprets natural language commands from network operators to automatically generate the necessary YAML configuration files.

Key Features:
  • Natural Language Interface: Utilizes a HuggingFace-integrated Mistral model to understand user requests for configuring components like gNBs (5G base stations) and UEs (User Equipment).
  • Automated YAML Generation: Translates parsed user commands into valid, structured YAML configuration files, eliminating manual coding.
  • Real-time Network Simulation: Integrates with UERANSIM to simulate the 5G network components based on the generated configurations.
  • Live Monitoring & Validation: Employs Prometheus and Grafana to provide a live dashboard for monitoring network performance.
Tech Stack: Python, Mistral LLM, HuggingFace, UERANSIM, Prometheus, Grafana, YAML

NLP with FastText: Word Embeddings & Classification

NLP Machine Learning FastText Word Embeddings

An exploration into Natural Language Processing that leverages the FastText library to perform two distinct tasks: unsupervised word embedding generation and supervised text classification. This project highlights the power of FastText's subword information model to handle morphologically rich languages and out-of-vocabulary words effectively.

Key Implementations:
  • Indian Recipe Word Embeddings (Unsupervised): Developed and trained an unsupervised FastText model on a dataset of Indian recipes. The resulting word embeddings successfully capture the semantic relationships between ingredients and cooking methods, providing a foundation for recipe analysis and similarity comparison.
  • News Category Classification (Supervised): Built a supervised FastText model to classify news articles into predefined categories like politics, sports, and technology. The model was trained on a labeled dataset, demonstrating a practical application of text classification with high efficiency and accuracy.
Tech Stack: Python, FastText, Pandas, NLTK, Scikit-learn
